# Code Of Conduct

This project follows a simple standard: be respectful, specific, and careful
with other people's data.

Participants are expected to:

- Communicate with patience and good intent.
- Critique code and decisions, not people.
- Avoid harassment, insults, or discriminatory language.
- Protect sensitive student, recruiter, institutional, and operational data.
- Use synthetic data in public discussions and examples.

Maintainers may remove comments, issues, or contributions that violate these
expectations or expose private data.
