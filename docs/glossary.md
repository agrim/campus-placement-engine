# Glossary

| Term | Meaning |
|---|---|
| Active application | Candidate-company application whose status is neither `idle` nor final placement |
| Admin | User who can configure the system and override most controls |
| Application | Candidate-company row that carries live workflow state |
| Board | Role-aware operational view of applications grouped by status |
| Candidate | Student or participant in the placement process |
| Company tracker | User or screen scoped to one hiring organization |
| Connector | Out-of-process software package that consumes a governed Integration contract |
| Control room | Central placement-day coordination function |
| Event | Append-only application movement record |
| Floor coordinator | Operator confirming arrival and room-level movement |
| Idle | Candidate-company application is not active in the live process |
| Inside | Candidate is inside a company process or interview room |
| Integration | Institution-facing configured connection, such as one signed webhook endpoint |
| Mobile tracker | Operator moving candidates between control room and venues |
| Module | Trusted in-process Engine feature shipped in the Engine release; not an uploaded executable package or external Connector |
| Offer upgrade | Policy allowing a placed candidate to continue pursuing a higher/preferred offer |
| Panelist availability | Per-round roster status showing whether a configured panelist is active, on break, or unavailable |
| Placement freeze | Policy preventing non-admin placement decisions during sensitive periods |
| Preference request | Decision workflow for candidates wanted by multiple companies |
| Process round | Ordered company step such as test, GD, case, interview, HR, or offer |
| Readiness | Pre-live check covering workflow, backups, stale queues, conflicts, capacity, notifications, and users |
| Round schedule | Day/room/time/capacity/status row for a process round |
| Scoped user | User limited to a role, company, or board perspective |
| Send away | Move candidate away from a company after a request-away decision |
| Send in | Approve sending candidate into the company process |
| Slot assignment | Candidate assignment to one round schedule |
| Stale board | Board page whose submission is older than the configured threshold |
| Terminology label | Admin-configurable words such as Candidate/Student or Company/Recruiter rendered in human-facing screens |
| Text identity | Plain-text site name, tagline, and public page titles; no logo or image asset is required |
| Wanted alert | Open follow-up for a candidate who is missing, delayed, or needed |
| Workflow | Configured statuses and role-gated transitions for an institution |
